## API Точка Банк + Telegram Bot

### Основные функции

- **Просмотр балансов**: Получение информации о балансах счетов.
- **Система ролей**:
  - **Admin**: Полный доступ ко всем командам (добавление/удаление пользователей, изменение ролей).
  - **User**: Доступ к просмотру балансов.
  - **Guest**: Ограниченный доступ (только `/start` и `/help`).
- **Динамическое управление пользователями**:
  - Добавление новых пользователей.
  - Удаление пользователей.
  - Изменение ролей.
- **Логирование**: Все изменения в системе записываются в лог-файл.
- **Меню команд**: Автоматически обновляемое меню команд в зависимости от роли пользователя.

### Структура проекта

```
api-tochka-bank-bot/
│
├── config/                  # Конфигурационные файлы
│   ├── config.py            # Настройки (токены, URL, словари)
│   └── users.json           # Файл со списком пользователей и их ролями
│
├── logs/                    # Логи
│   └── user_logs.log        # Лог-файл для записи информации о пользователях
│
├── api/                     # Логика работы с API
│   ├── api_client.py        # Класс для работы с API банка Точка
│   └── __init__.py          # Инициализация пакета
│
├── core/                    # Бизнес-логика
│   ├── account_manager.py   # Логика получения счетов и балансов
│   └── __init__.py          # Инициализация пакета
│
├── users/                   # Управление пользователями и ролями
│   ├── permissions.py       # Управление ролями и правами доступа
│   └── __init__.py          # Инициализация пакета
│
├── bot/                     # Логика Telegram-бота
│   ├── handlers.py          # Обработчики команд бота
│   ├── logger.py            # Настройка логирования
│   ├── __init__.py          # Инициализация пакета
```

### Настройка конфигурации

- `config/config.py.orginal` переименовать в `config/config.py` 
- `config/users.json.original` переименовать в `users.json`
- В файле `config/config.py` указать токен вашего Telegram-бота (`TELEGRAM_BOT_TOKEN`) и API-токен банка "Точка" (`API_TOKEN`).
- Настроить список пользователей и их роли в файле `config/users.json`. Имя пользователя - это ID пользователя Телеграм, которому разрешается доступ к функционалу чат-бота.

### Установка и запуск

Убедитесь, что у вас установлен Python 3.10 или выше. Затем установите зависимости:

```bash
pip install -r requirements.txt
```
Запуск бота с помощью команды:

```bash
python main.py
```
